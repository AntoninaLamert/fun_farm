# Работа с проектом

Репозиторий игры: https://github.com/AntoninaLamert/fun_farm

Пользователь разрешил отправлять все дальнейшие изменения этой игры на GitHub без повторного подтверждения. После завершения изменений создавай коммит и отправляй его в origin/main. Не перезаписывай удалённую историю принудительной отправкой. Если отправка недоступна, сохрани изменения локально и сообщи об этом пользователю.

Для доступа используй настроенный Git Credential Manager. Токен хранится в защищённом хранилище Windows; не добавляй токены в файлы проекта, URL репозитория или сообщения коммитов.

Игра должна запускаться через index.html без сервера и сборки. Сохраняй относительные пути к ресурсам.
