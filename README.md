# Весёлая ферма — этап 1

Откройте `index.html` двойным нажатием. Сервер, установка пакетов и подключение к интернету не нужны. Для публикации на GitHub Pages перенесите всю папку проекта вместе с `assets`.

В проекте только интерфейс: все товары в магазине, заказах и на складе, а также стрелка реагируют на наведение, фокус и нажатие мышью или клавишами Enter/Пробел. Покупок, посадки, роста и сбора урожая пока нет. На поле находятся три отдельные стартовые грядки без сетки некупленных клеток. По согласованию вместо отсутствующей в атласе тыквы используется кукуруза.

- `index.html` — разметка четырёх рядов интерфейса.
- `styles.css` — расположение, оформление HTML-текста и общее масштабирование.
- `sprites.js` — координаты в исходном атласе, отрисовка спрайтов и масштабируемых рамок.
- `economy.js` — каталог и цены первого этапа.
- `game.js` — состояние демонстрации и отдельные функции отображения.
- `assets/atlas.png` — приложенный PNG-атлас без изменений.

Игровая территория использует координаты 1400 × 340 независимо от окна. Координаты и растения стартовых грядок хранятся в `FarmGame.state.beds`. `FarmGame.field.clientToLogical` переводит координаты указателя в координаты территории. `FarmGame.view` предоставляет функции обновления отдельных областей, а `FarmGame.events` оставлен для подключения событий следующего этапа.

Фон неба и травы рисуется на всю область браузера, отдельно от масштабируемых панелей. Трава внутри ограды и снаружи использует общую привязку текстуры. Спрайты изолируются из атласа до масштабирования; рамки собираются с целыми углами и винтиками, без захвата соседних изображений. Чтение пикселей и сервер для этого не нужны.

Порядок товаров повторяет цветной макет; цены взяты из текущего задания: морковь 10, яблоко 50, помидор 100, кукуруза 300, новая грядка 100. Все количества и цены — HTML-текст. По уточнённому макету под синей стрелкой находится светлая панель с деревянной рамкой из атласа.

Интерактивная область товара — только его изображение. Подложки и числовые показатели остаются неподвижными; наведение на них не активирует товар. Нажатия изображений отправляют событие `product:activate` через `FarmGame.events`, с `productId` и `section` (`shop`, `orders`, `warehouse`) в `detail`. Стрелка отправляет `delivery:activate`. На первом этапе эти события дают визуальный отклик и не меняют состояние игры.

Браузер и тесты не запускались по просьбе пользователя.
